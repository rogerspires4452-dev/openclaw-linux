An opinionated Linux experience built around OpenClaw — the gateway as the
center of a personal machine. Born on Omarchy/Arch (beelink) from real
battle scars; designed to be maintained by humans *and* bots.

## Vision

- Phase 1: a provisioner that turns a fresh Arch/Omarchy box into an OpenClaw
  appliance: gateway service, dev-channel updates, pre-update backups,
  dashboard app-mode as the default window, first-boot pairing wizard.
- Phase 2: an archiso profile producing a bootable install disk.
